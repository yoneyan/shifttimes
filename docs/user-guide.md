## 用語

| 用語 | 意味 |
|---|---|
| グループ | 店舗や団体の単位。シフトも勤怠も課金もグループごとに管理します |
| グループ管理者 | グループの設定変更やメンバー登録ができる人 |
| 勤務時間 | シフト希望を入力する時間帯（例：早番 9:00〜13:00）。グループごとに設定します |
| シフト希望 | 「この日のこの時間帯なら働ける」という申告。確定したシフトそのものではありません |
| 開講区分 | 日付ごとの営業状態（営業日・休業日など）。「シフト入力不可」の区分を設定できます |
| 提出期限 | シフト希望を受け付ける対象期間と締切日 |

## はじめに（全員）

### アカウントを有効にする

グループ管理者がアカウントを作成すると、登録したメールアドレスに
有効化 URL が届きます。URL を開くとアカウントが有効になり、ログインできます。

有効化 URL の期限は既定で 72 時間です。期限が切れた場合はグループ管理者に
再登録を依頼してください。

### ログインする

トップページの「ログイン」からユーザ名とパスワードを入力します。

### プロフィールを変更する

画面右上の表示名メニューから「アカウント情報」を開きます。

| できること | 場所 |
|---|---|
| 表示名・氏名の変更 | アカウント情報 → プロフィール編集（表示名メニューからも直接開けます） |
| パスワードの変更 | アカウント情報 → パスワード変更（表示名メニューからも直接開けます） |
| メールアドレスの変更 | アカウント情報 → メールアドレス |
| 2 段階認証の設定 | アカウント情報 → 2段階認証 |

> メールアドレスを変更すると、新しいアドレス宛に有効化メールが送られ、
> それを開くまでアカウントは一時的に無効になります。

## メンバー向け

### シフト希望を登録する

ナビゲーションの「シフト管理」を開くと、所属しているグループが一覧で出ます。
各グループのカードに、提出期限と下書きの件数が表示されます。

登録方法は 2 つあります。

#### 一覧表から登録する（まとめて入力したいとき）

カードの **シフト希望を登録** を押すと、月ごとに日付 × 時間帯の表が出ます。
日付をタップすると、その日の希望をまとめて登録するダイアログが開きます。

ダイアログでは次の 2 つの入れ方ができます。

- **日付単位** — その 1 日だけに反映する
- **曜日一括** — 対象期間内の同じ曜日すべてに反映する（毎週月曜は入れない、など）

#### カレンダーで確認する

カードの **カレンダーで見る** を押すと、自分の希望が月カレンダーで表示されます。

| 記号 | 意味 |
|---|---|
| ○ | 勤務可能 |
| △ | 要相談 |
| × | 勤務不可 |

#### 下書きと確定について

登録した希望は最初「下書き」として保存されます。
下書きのままでもグループ管理者からは見えますが、確定済みとは区別されます。

**確定は自分で行います。** 一覧表の画面にある確定ボタン、または
「お知らせ」画面に出る下書きの案内から、自分の下書きをまとめて確定できます。
確定できるのは自分の希望だけで、他のメンバーのぶんには影響しません。

確定すると、シフト管理のグループカードに出ている下書き件数が減ります。

#### 入力できない日について

次の場合は入力できません。

- 開講区分に「シフト入力不可」が設定されている日（休業日など）
- 提出期限を過ぎている対象期間

提出期限が設定されていないグループでは、今月初日から来月末日までが
既定の入力対象期間になります。

### 開講スケジュールを確認する

`/shift/schedule/<グループID>/view/` で、日付ごとの営業状態を月カレンダーで
確認できます。設定はグループ管理者が行います。

### 勤怠を記録する

グループ管理者が勤怠管理を有効にしている場合のみ、ナビゲーションに「勤怠」が出ます。
シフト管理のグループカードにある **勤怠** ボタンからも開けます。

#### 打刻で記録する

勤怠画面の **出勤** ボタン・**退勤** ボタンを押すと、その時刻が記録されます。
退勤時には実働時間（休憩を差し引いたもの）が表示されます。

- 出勤を押していない状態で退勤を押すとエラーになります
- 同じ日に 2 回出勤を押しても、最初の時刻が保持されます
- 日をまたぐ夜勤の場合、前日の退勤が未記録であれば警告が出ます。
  その場合は一覧表から手動で修正してください

#### 手動で入力する

グループ管理者が手動入力を許可している場合、月ごとの一覧表から
出勤時刻・退勤時刻・休憩時間（分）を直接入力できます。
出勤と退勤の両方を空にして保存すると、その日の記録は削除されます。

画面下部にその月の勤務日数と実働時間の合計が出ます。

### 2 段階認証を設定する

「アカウント情報 → 2段階認証 → 追加」で QR コードが表示されます。
認証アプリ（Google Authenticator など）で読み取ると登録されます。
1 ユーザにつき最大 5 台まで登録できます。

## グループ管理者向け

### 管理者ページ

「グループ → 対象グループ → 管理者ページ」が操作の起点です。
ナビゲーションの **管理メニュー** からは「シフト提出状況」「開講スケジュール設定」
「勤怠集計・設定」へ直接移動できます（グループ管理者にだけ表示されます）。
ページ上部に現在のメンバー数・上限・契約プランが表示されます。
上限に達している場合は赤く表示され、請求管理への導線が出ます。

### メンバーを登録する

管理者ページの **ユーザ登録** から、ユーザ名（英語・日本語）、表示名、
メールアドレス、パスワードを入力して登録します。
登録すると本人宛に有効化メールが送られます。

**ユーザ登録（管理者）** を使うと、そのユーザにグループ管理者権限を付けた状態で
登録できます。

> **メンバー数が上限に達している場合**、登録フォームは無効になり、
> プラン確認への案内が出ます。プランをアップグレードするか、
> メンバーを減らしてから登録してください。

### 権限を設定する

管理者ページの **権限設定** から、メンバーごとに管理者権限の付与・解除ができます。

### 開講スケジュールと提出期限を設定する

管理者ページの **開講スケジュール設定** から行います。勤務時間・開講区分・
日付ごとの割り当て・提出期限をこの 1 画面で設定します。

#### 勤務時間

メンバーがシフト希望を入力するときの時間帯です。名前と開始・終了時刻を登録します。
**追加** から新しい時間帯を作成し、一覧の行をタップすると名前や時刻を変更できます。

- 勤務時間はグループごとに管理されます。他のグループの設定には影響しません
- 勤務時間が 1 件も登録されていないグループには、早番・中番・遅番の 3 件が自動で用意されます
- 使わなくなった時間帯は「有効」を外してください。新しい入力には表示されなくなり、
  過去のシフト希望や集計はそのまま残ります
- シフト希望が 1 件も登録されていない時間帯だけ、ダイアログの **削除** で完全に削除できます

#### 開講区分

日付ごとの営業状態です。区分には「シフト入力不可」のフラグを付けられます。
休業日など、希望を出させたくない日に使います。

区分ごとに **表示色** を設定できます。カレンダーの日付バッジ・凡例・提出状況の色に使われます。
ダイアログのカラーピッカーで自由に選べるほか、並んでいる色見本を押すとその色になります。

カレンダーで日付を選び、区分と備考を設定します。
区分を未指定にして保存すると、その日の設定が削除されます。

#### 提出期限

対象期間（開始日・終了日）と提出期限日を登録します。
期限を過ぎるとメンバーはその期間の希望を入力できなくなります。

提出期限を 1 件も登録していない場合、メンバーは今月初日から来月末日までを
入力できます。

### シフトの提出状況を確認する

管理者ページの **シフト提出状況** で、メンバー × 日付の提出状況を一覧できます。
誰がまだ出していないかを確認するのに使います。

> シフト希望の確定は各メンバーが自分で行います。管理者がまとめて確定することは
> できません。未確定のメンバーがいる場合は、提出状況の画面で確認して本人に依頼してください。

### 勤怠管理を有効にする

管理者ページの **勤怠設定** から設定します。

| 設定 | 内容 |
|---|---|
| 勤怠管理を利用する | オフの間、メンバーのナビゲーションに「勤怠」は出ません |
| 手動入力を許可 | 一覧表からの直接入力を許可するか |
| 出退勤ボタンを許可 | 打刻ボタンを使えるようにするか |

### 勤怠を集計する

管理者ページの **勤怠集計** で、メンバー × 日付の勤怠を一覧できます。
セルから個々の勤怠を修正することもできます。

### プランを契約・変更する

管理者ページの **請求管理** から操作します。

#### 現在の状態を見る

画面上部のカードに、契約中のプラン、メンバー数と上限、次回更新日が出ます。
運営から無償付与を受けている場合は「無償付与」のバッジと、その理由・期限が表示されます。

#### 新しく契約する

プラン一覧から選んで「このプランで始める」を押すと、Stripe の決済ページへ移動します。
決済が完了すると契約が反映されます。

#### プランを変更する

契約中でも他のプランに変更できます。差額は日割りで精算されます。

> **ダウングレードの制限**: 現在のメンバー数が移行先プランの上限を超えている場合、
> ボタンは無効になり理由が表示されます。先にメンバーを減らしてください。

#### 支払い方法を変更する・請求書を見る

「支払い方法・請求書の管理」から Stripe のカスタマーポータルへ移動します。
カード情報の変更、過去の請求書のダウンロードはここで行います。

#### 解約する

「サブスクリプションを解約する」を押すと、**現在の請求期間の終了日で解約**されます。
即時に使えなくなるわけではなく、支払い済みの期間は最後まで利用できます。

解約を予約すると「解約を取り消して継続する」ボタンが出ます。
終了日までであれば、いつでも解約を取り消せます。

解約後はメンバー数の上限が Free プラン（既定 10 名）に戻ります。
上限を超えていても既存メンバーが削除されることはありませんが、
新しいメンバーを追加できなくなります。

#### 支払いに失敗したとき

カードの期限切れなどで支払いに失敗すると、請求管理の画面に赤い警告が出ます。
この間もサービスは利用できます（Stripe が自動で再試行します）。
「支払い方法・請求書の管理」からカード情報を更新してください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 有効化メールが届かない | 迷惑メールフォルダを確認。期限（72 時間）切れならグループ管理者に再登録を依頼 |
| シフト希望が入力できない | 提出期限を過ぎていないか、その日が「シフト入力不可」の区分でないかを確認 |
| ナビゲーションに「勤怠」が出ない | グループ管理者が勤怠管理を有効にしていない |
| 出退勤ボタンがない | グループ管理者が「出退勤ボタンを許可」をオフにしている |
| メンバーを追加できない | プランのメンバー数上限。請求管理からプランを確認 |
| 申し込みボタンが「準備中」 | そのプランの Stripe 設定が未完了。運営へ問い合わせ |
| 請求画面に「Stripe が未設定」と出る | サーバ側の設定が未完了。運営へ問い合わせ |
| パスワードを忘れた | ログイン画面の「パスワードをお忘れですか？」から再設定 |
